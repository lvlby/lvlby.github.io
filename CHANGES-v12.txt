LvLBY v12 - what changed (from v11)

1. "Client is offline" error
   - Firestore now uses forced long-polling (works better on filtered networks).
   - If the cloud cannot be reached, the app no longer shows an error. It keeps your data on the device, shows a calm message, and retries automatically (6s, 12s, ... up to 60s) and again when the phone comes back online.
   - Fixed a second hidden bug: Firebase setup could register twice.
   NOT guaranteed: if firestore.googleapis.com is fully blocked on the user's network, cloud sync cannot work. The app still works locally.

2. Questions popup
   - Cause found: the only line that opened the questions was accidentally inside the notifications button, so it never opened on first visit.
   - Now: a welcome popup with a big "Start the questions / شروع سؤال‌ها" button opens on first visit (and for users who have not finished the questions). A big card with the same button also sits on top of the main screen until the questions are done. "Later / بعداً" closes the popup.

3. Persian (checked by running the page in a real headless browser at phone size)
   - Brand "LvLBY." showed the dot on the wrong side: fixed.
   - Native date box showed English "10/25/2026": in Persian it now shows the Persian date (the date picker itself still opens when tapped; the picker window is the browser's own).
   - Tab bar labels wrapped on 3 lines: shortened (روتین‌ها، هفته، گزارش).
   - Language button now says "English" / "فارسی". Privacy link is Persian in Persian mode.
   - "XP" text order was reversed: fixed. Google button no longer breaks into 3 lines.
   - Date commas are Persian (،).
   - Automatic scan of every tab found no leftover English words except "XP".
   - I did NOT read every Persian sentence for style/grammar. I checked: missing translations (none), Arabic letters/digits (none), spacing of "می‌" prefixes (none wrong). A native-speaker read-through is still recommended.

4. Not done
   - "Profile picture when installed as an app": waiting for your answer (see chat).
   - Not tested on a real phone or real Iranian network.

v13 - Smart Add repeats
Smart Add now understands (English and Persian):
  every 2 days / every three days / every other day      هر ۲ روز / هر سه روز / یک روز در میان
  every 2 weeks (optionally on a weekday)                هر دو هفته دوشنبه
  every day for one week / till one week / for 3 weeks   هر روز به مدت یک هفته / برای ۲ هفته
  "for/till N days, weeks, months" alone = every day until that period ends (max 1 year)
The preview line shows the repeat and the end date before you confirm. Repeats are saved in "My routines".
Limits: "for 2 hours" is NOT treated as a repeat. In the Habits tab, such items are not yet shown with their interval (they still appear on the right days).

v15 - "Building your routine" screen

v36 - Google sign-in inside the Android app
Why: in the app the old Google button used a pop-up page (Firebase "signInWithPopup"), which an Android WebView cannot do. It ended with "The requested action is invalid." The website was never affected.
Added: in the app only, the Google button now opens Android's own Google account picker (plugin @capacitor-firebase/authentication 6.x). The ID token it returns is given to the same Firebase web login (signInWithCredential), so it is the same account, the same cloud data and the same sync as the website. Cancelling shows the calm "cancelled" text without the error toast; other errors show the plugin's message (for example 10 / DEVELOPER_ERROR). Sign-out signs out of both the native side and the web side. Deleting the account asks for a fresh Google login the native way in the app.
Added (build): the plugins are bundled into one file (native-plugins.js, made by esbuild in the GitHub workflow) because the page has no bundler; the page loads it only inside the app. The workflow also sets the Android variables the plugin needs (rgcfaIncludeGoogle, androidxCredentialsVersion), and can sign every build with ONE fixed key (three GitHub secrets). It then prints the APK's SHA-1/SHA-256 and warns if the SHA-1 is not in google-services.json.
Changed: the website behaves exactly as before (popup / redirect login, email login, Firestore sync untouched). The reminder and backup code now finds its plugins through the same bundle.
Why a fixed key: without it every GitHub build gets a new random signing key, so the SHA-1 registered in Firebase can never match the next APK and Google rejects the sign-in.
Not done: Firebase and Firestore still need the whole phone to reach Google (a VPN in Iran). Loading the Firebase web SDK from the app's own files instead of gstatic is possible later. Google sign-in needs Google Play services and a Google account on the phone.
Tested: with a fake Google plugin and a fake Firebase in Chromium: website popup unchanged; app signs in with the ID token and never uses the pop-up; cancel, plugin error and missing-token paths; sign-out on both sides; email login still reachable; all older suites still pass. NOT tested: the GitHub build (esbuild bundle, Gradle with the plugin), the real plugin, a real Google sign-in, a real phone.

v38.1 - routine and school tasks can be edited for all days
Fixed: changing the name or time of a routine or school task in the daily plan only changed that one day. The task window now has a switch "Apply the name and time to all days from this day on" (on by default, only for routine and school tasks). Earlier days stay as they were. Morning-routine times are converted back for the afternoon shift.

v39 - Smart Add ranges and Persian dates, focus timer, countdown, weekly review, phone-free streak
Added: Smart Add understands time ranges: "2:00-5:00", "2:00 - 5:00", "2:00 till 5:00", "from 2 to 5 pm", "10 am until 2 pm", Persian "ساعت ۲ تا ۵ عصر", "از ساعت ۹ تا ۱۱ صبح". Without am/pm the app asks AM or PM once, as always. The end time is saved on the task (field end), shown in the list as 2:00-5:00, editable in the task window ("Until") and used as the end of calendar events (.ics).
Added: Smart Add understands Persian-calendar dates written in English letters or Persian: all 12 months with common spellings (aban, abaan, Aban, Azar, Dey, Khordad, Esfand ...), and the day as 27, 27th, twenty seventh, twenty-seventh, "the 27th of aban", "aban 27", ۲۷, ۲۷م, بیست و هفتم, بیست‌وهفتم. Gregorian ordinals also work ("twenty seventh November"). A question like "Did you buy your PC on 27 aban" keeps the question as the title.
Added: Focus timer window (15, 25 or 45 minutes, notification in the Android app, +10 XP per finished session), countdown cards for the next exams (students), weekly review lines (most missed habit, hardest day, phone-free days), phone-free streak (choose 2 or more apps to stay away from, confirm each day; nothing is blocked and the app list stays on the device).
Added: Settings (website only) has a "Download the Android app" button that downloads the newest APK from GitHub in one tap, with the install steps right under it and a link to download.html. It replaces the separate "Get the Android app" button. Hidden inside the app.
Fixed (Persian): time ranges without the word "ساعت" ("۲ تا ۵ عصر") and ranges that end with "شب" or "ظهر" ("ساعت ۷ تا ۸ شب") are understood without asking AM or PM. All 12 Persian months in every form were re-tested (digits, ordinals, with and without a year) with no failures; Persian screens, Help, What's new, focus timer and the task window were checked for leftover English text and sideways scrolling.
